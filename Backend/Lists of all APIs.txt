🧩 Custom Endpoints
📘 Term → Session Relationship
GET /api/sessions/{session_id}/terms/
→ Get all terms under a specific session

📘 Subject → Class Relationship
GET /api/classes/{class_id}/subjects/
→ Get all subjects for a specific class

📘 Bulk Enrollment
POST /api/bulk/enrollments/
→ Bulk enroll multiple students at once

📘 Students in a Subject in a Class
GET /api/stu/class/{class_id}/subjects/{subject_id}/students/
→ Get all students in a class offering a specific subject

📘 Scores Input
POST /api/scores/input/subject/{subject_id}/class/{class_id}/term/{term_id}/
→ Input scores for multiple students for a specific subject, class, and term

📘 Student-Specific Scores
GET /api/scores/student/{student_id}/
→ Retrieve all scores for a particular student

📘 Filter Scores (Flexible)
GET /api/scores/filter/?subject_id=&class_id=&student_id=&term_id=
→ Retrieve scores with filtering options
(Can be filtered by one or more of: subject, class, student, term)
